KTin 2.7.20 - GMCP 지도창 확장 및 하이라이트 편집기 추가
============================================================

1. GMCP 지도 팝업창
-------------------
- 제목 표시줄에 표준 최소화/최대화 버튼을 사용할 수 있습니다.
- 창 테두리와 오른쪽 아래 크기 조절 손잡이를 드래그해 크기를 바꿀 수 있습니다.
- 사용자가 직접 크기를 바꾼 뒤에는 GMCP 지도 갱신이 창 크기를 자동으로 되돌리지 않습니다.
- 창 최소 크기: 380 x 220
- 사용자 지정 최대 폭 제한을 4096픽셀로 확장했습니다.

2. GMCP 지도 저장
-----------------
- 지도창 아래의 '이동 취소' 오른쪽에 '저장' 버튼을 추가했습니다.
- 저장 위치:

    KTin 실행파일 디렉터리\map\지역명.txt

- map 폴더가 없으면 자동으로 생성합니다.
- GMCP room.info의 zone 값을 지역명으로 사용합니다.
- Windows 파일명에 사용할 수 없는 문자는 밑줄(_)로 바꿉니다.
- 지역명이 비어 있으면 GMCP지도.txt로 저장합니다.
- UTF-8 BOM 형식으로 저장합니다.

3. 하이라이트 편집기
--------------------
- 메뉴 위치:

    편집 -> 트리거 편집 다음 -> 하이라이트 편집(&H)...

- 트리거 편집기와 같은 주소록 스크립트 파일(.tin)을 사용합니다.
- 별도 KTin 관리 구역만 추가/교체하므로 기존 수동 스크립트와 트리거 관리 구역은 보존합니다.
- 폴더/하위 폴더/CLASS/사용 여부를 트리거 편집기와 같은 방식으로 관리합니다.
- 하이라이트 항목:
  · 이름
  · 사용
  · CLASS
  · 인식 패턴
  · 글자색 16색
  · 배경색 16색
  · 글자색/배경색 직접 선택
  · 반전
- 색상을 고르지 않고 반전만 선택할 수 있습니다.
- '저장 후 적용'은 파일을 저장한 뒤 현재 TinTin++ 백엔드에서 같은 파일을 다시 읽습니다.
- 저장 전 기존 파일을 같은 경로의 .bak 파일로 백업합니다.

4. TinTin++ 저장 구문
---------------------
하이라이트 실행 구문은 다음 순서로 저장합니다.

    #highlight {인식 패턴} {색상 지정} {우선순위}

예:

    #highlight {경험치를 얻었습니다} {Red} {5}
    #highlight {위험} {White b red} {5}
    #highlight {중요 알림} {reverse} {5}

- 배경색은 색상 지정 안에서 b 다음에 기록합니다.
- 반전은 reverse로 기록합니다.
- 직접 선택한 RGB 색상은 TinTin++의 <rgb> 형식으로 변환합니다.

6. 빌드
-------
WSL MinGW 빌드 예:

    cd /mnt/d/ktin
    make clean
    make -j"$(nproc)"

Visual Studio/MSVC 빌드는 기존 build_msvc.bat 또는 기존 솔루션 빌드 절차를 사용합니다.

7. 권장 시험
------------
[GMCP 지도]
1) 보기 -> GMCP 지도 보기를 엽니다.
2) 최소화 후 복원합니다.
3) 최대화 후 복원합니다.
4) 오른쪽 아래 손잡이와 창 테두리를 드래그합니다.
5) GMCP 정보가 새로 들어와도 사용자 지정 크기가 유지되는지 확인합니다.
6) 저장을 눌러 map\지역명.txt 내용과 한글 파일명을 확인합니다.

[하이라이트]
1) 편집 -> 하이라이트 편집을 엽니다.
2) 폴더와 하이라이트를 추가합니다.
3) 글자색만, 배경색만, 글자색+배경색을 각각 시험합니다.
4) 색상 없이 반전만 체크한 항목을 시험합니다.
5) 폴더 사용을 끄면 내부 하이라이트가 모두 적용되지 않는지 확인합니다.
6) 저장 후 적용 뒤 출력 문자열 색상이 즉시 바뀌는지 확인합니다.
7) 같은 .tin 파일의 트리거 관리 구역과 수동 스크립트가 유지되는지 확인합니다.
