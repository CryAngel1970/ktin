KTin 2.6-a04 build fix 36
==========================

수정 내용
---------
- 기본 입력창은 단일 행 EDIT 컨트롤이어서 여러 행 텍스트를 붙여넣으면 첫 줄만 남던 문제를 수정했습니다.
- 입력창에서 Ctrl+V, Shift+Insert, 우클릭 붙여넣기 등으로 WM_PASTE가 들어올 때 클립보드에 줄바꿈이 있으면 전체 내용을 감지합니다.
- CRLF(Windows), LF(Unix), CR(Mac) 줄바꿈을 모두 ConPTY의 Enter 입력인 CR로 통일해 TinTin++로 한 번에 전달합니다.
- 클립보드 마지막 줄에 줄바꿈이 없어도 마지막 줄까지 전송합니다.
- 빈 줄이 여러 개 포함된 경우에도 줄 수를 유지합니다.
- 한 줄짜리 클립보드는 기존처럼 현재 입력창에 붙여넣습니다.
- 붙여넣기 과정은 클립보드를 읽기만 하며 원래 클립보드 내용을 변경하지 않습니다.

수정 파일
---------
- input.cpp
- utils.cpp
- utils.h

사용 예
-------
1. MUD 게시판에서 글쓰기 모드로 들어갑니다.
2. 메모장에서 여러 행의 본문을 복사합니다.
3. KTin 입력창에서 Ctrl+V를 누릅니다.
4. 여러 행이 즉시 순서대로 MUD에 전달됩니다.
5. 입력창에 마침표(.)를 입력하고 Enter를 눌러 글쓰기를 끝냅니다.

확인 항목
---------
- 한 줄 붙여넣기는 입력창에만 들어가는지 확인합니다.
- 두 줄 이상 붙여넣으면 모든 줄이 MUD 글쓰기 모드에 들어가는지 확인합니다.
- 본문 중간의 빈 줄이 유지되는지 확인합니다.
- 한글, 영문, 특수문자가 깨지지 않는지 확인합니다.
- 붙여넣기 후 Windows 클립보드 원문이 그대로 남아 있는지 확인합니다.

추가 수정: 전각·모호한 동아시아 문자 행의 빈 행 보정
---------------------------------------------------
- 지도뿐 아니라 박스 테두리, 전각 기호, 도형 문자가 들어간 고정폭 출력에서도 한 줄씩
  빈 행이 끼어 보이던 문제를 수정했습니다.
- 서버 또는 ConPTY가 한 줄을 화면 폭만큼 ASCII 공백으로 채워 보내는 경우, KTin이
  모호한 동아시아 문자를 2칸으로 계산하면서 줄의 계산 폭이 ConPTY보다 길어졌습니다.
- 그 결과 줄 끝의 채움 공백 일부가 다음 행으로 자동 줄바꿈되어, 공백만 있는 행이 실제
  터미널 버퍼에 하나씩 추가됐습니다. 환경설정 창을 닫으면 ConPTY 크기 재설정과 화면
  재출력이 일어나 기존 공백 행이 사라져 보였습니다.
- 현재 행에 2칸 문자가 있고 오른쪽 끝 자동 줄바꿈 대기 상태일 때 뒤따르는 ASCII 공백은
  줄 끝 채움으로 보고 버리도록 했습니다. 일반 본문 공백과 실제 다음 줄 문자는 유지됩니다.
- 효과가 없었던 전체 화면 강제 다시 그리기 보정은 제거하고 기존 부분 갱신 방식으로
  되돌렸습니다.

추가 수정: 새 창별 세션 및 자동 재연결 분리
-------------------------------------------
- 빠른 연결의 고정 TinTin++ 세션명 `new`와 주소록 표시 이름을 실제 세션 식별자로
  재사용하던 구조를 제거했습니다.
- 각 KTin 프로세스 ID와 접속 순번을 조합해 빠른 연결과 주소록 접속마다 고유한
  내부 세션명을 생성합니다.
- 주소록의 이름은 화면 표시용으로만 사용하며 세션 종료와 재연결에는 사용하지 않습니다.
- 자동 재연결은 현재 창이 메모리에 보관한 주소록 항목 사본만 사용합니다.
- 연결이 끊기면 기존 내부 세션을 먼저 정리하고 500ms 뒤 새 내부 세션명으로
  다시 연결하므로, 이전 세션이나 다른 창의 서버로 전환되지 않습니다.
- 세션 전환을 위해 보낸 `#zap`의 종료 문구는 자동 재연결 실패로 오인하지 않습니다.
- 자동 연결 전환에서는 KTin이 직접 만든 내부 세션만 이름으로 종료합니다.
  추적 중인 세션이 없을 때는 인자 없는 `#zap`을 보내지 않습니다.
- 주소록은 변경 시 즉시 저장하고, 각 창 종료 시 오래된 주소록 사본을 다시 저장하지 않아
  다른 창의 주소록 변경을 덮어쓰지 않습니다.

## 블럭·화면 복사/저장 확장 및 ANSI 코드 보존

- `블럭 설정 후`에 일반/ANSI 클립보드, 일반/ANSI 파일저장, 선택메뉴의 다섯 동작을 제공합니다.
- 선택메뉴에는 `복사하기 / 파일저장 / 코드로 복사하기 / 코드로 파일저장 / 닫기`가 표시됩니다.
- 로그창 오른쪽 클릭 메뉴는 `복사하기 > / 파일저장 > / 지우기 > / 닫기` 하위 메뉴로 확장됩니다.
- 현재화면, 선택블럭, 지난화면, 전체화면을 각각 일반 텍스트 또는 ANSI 코드 포함 텍스트로 복사/저장할 수 있습니다.
- `코드로` 내보내기는 화면 셀의 글자색·배경색·굵기를 ANSI SGR true-color 코드로 재구성하며 각 행 끝에서 색상을 초기화합니다.
- 일반 텍스트 파일은 UTF-8 BOM, ANSI 코드 포함 파일은 실제 ESC 바이트가 보존되도록 UTF-8(BOM 없음)으로 저장합니다.
- 저장 대화상자의 기본 폴더는 실행 파일 옆 `저장` 폴더이고, 기본 파일명은 `YYYYMMDD_HHMMSS.txt`입니다.
- 편집 메뉴의 `지난 화면을 / 현재 화면을 / 전체 화면을`에도 복사·저장·ANSI 복사·ANSI 저장·지우기를 제공합니다.
- 기존 블럭 동작 설정값은 새 드롭다운 순서로 자동 이전됩니다.
