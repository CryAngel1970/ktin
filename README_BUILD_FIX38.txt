KTin 2.7.20 - BUILD FIX38
하이라이트 편집창 글꼴 크기 통일

수정 내용
1. 하이라이트 편집창의 모든 자식 컨트롤 글꼴을 트리거 편집창과 동일한 GetPopupUIFont()로 적용했습니다.
2. 폴더/하이라이트 이름 입력 보조창도 트리거 편집창의 이름 입력창과 같은 글꼴을 사용합니다.
3. 기존 GetCurrentAppFont(9)로 생성하던 작은 9픽셀 고정폭 글꼴을 제거해 버튼, 목록, 레이블, 입력란의 표시 크기가 트리거 편집창과 일치합니다.
4. 매번 새 HFONT를 생성하던 경로도 제거되어 하이라이트 창을 반복해서 열 때 발생할 수 있던 GDI 글꼴 누수를 방지합니다.

수정 파일
- highlight.cpp
- README_BUILD_FIX38.txt

빌드
Visual Studio에서 Release x86 구성으로 솔루션을 다시 빌드하십시오.

확인 항목
- 편집 > 트리거 편집과 편집 > 하이라이트 편집을 차례로 열어 글꼴 크기를 비교합니다.
- 하이라이트 트리 목록, 상세 편집 레이블, 이름/CLASS/인식 패턴 입력란, 버튼 글꼴이 트리거 편집창과 같은 크기인지 확인합니다.
- 폴더 추가 또는 하이라이트 추가 시 열리는 이름 입력창 글꼴도 같은 크기인지 확인합니다.
